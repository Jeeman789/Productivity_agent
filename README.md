# Productivity_agent
An attempt at making an agent who can interact with raspberry pi and help increase my productivity

## Install Hermes Agent

Hermes Agent is distributed as a standalone Python/CLI application, not as an npm package. On Windows, install it from PowerShell with the official installer:

```powershell
iex (irm https://hermes-agent.nousresearch.com/install.ps1)
```

After installation, start the setup wizard and launch Hermes:

```powershell
hermes setup
hermes
```

See the [official Hermes Agent documentation](https://hermes-agent.nousresearch.com/docs/) for provider configuration and integrations.
